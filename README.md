# FreeNeuro v1.2 — бесплатные нейросети на твоём телефоне

Приложение-клиент (Android APK) + сервер на Python (FastAPI). Все нейросети — бесплатные:
OpenRouter, Groq, Google Gemini, свои OpenAI-совместимые эндпоинты (CometAPI и любые другие)
и Pollinations вообще без ключа. Когда у модели кончается лимит или ключ не работает —
сервер сам переключается на следующую, от лучшей к худшей.

## Что умеет v1.2

**Песочница файлов (у каждого чата своя)**
- Кнопка с папкой на панели — файловый менеджер: закинуть, скачать, удалить, переместить/переименовать.
- Файлы хранятся на сервере; нейросеть читает их сама как современные ИИ:
  PDF (текстовый слой), DOCX, XLSX, PPTX, CSV, код и текст — извлекаются в текст;
  картинки передаются vision-моделям как пиксели, **без сжатия**.
- В чате можно прикрепить файл с устройства (любой тип) или из песочницы;
  фото открываются из галереи, а не из файлового проводника.
- ИИ сам работает с песочницей как агент: `sandbox_read`, `sandbox_write`,
  `sandbox_share` (прикрепляет файл к ответу — со ссылкой для скачивания), `sandbox_delete`.
- Скачивание работает прямо из приложения (DownloadManager).

**Разные чаты** — каждый чат: своя история, своё сжатие, своя песочница.
**Поиск в чате** — ищет по всем сообщениям текущего чата и перепрыгивает к нужному.

**Уточнение промпта** — кнопка с волшебной палочкой у поля ввода. Включаешь её,
описываешь задачу как попало — ИИ задаёт вопросы по одному, пока не соберёт
правильный подробный промпт, и кладёт его в поле ввода (можно отредактировать и отправить).

**Память и сжатие**
- ИИ сам запоминает важное о тебе (`memory_add`), а кнопкой «Сжать память»
  нейросеть объединяет повторы, удаляет лишнее и оставляет нужное.
- Длинная история чата сжимается автоматически в краткое содержание —
  старые сообщения не теряют смысл, а контекст не переполняется.
- Поиск по чату — в шапке.

**Приоритеты моделей (словарь)**
- В настройках — полный список: от умных сверху до простых снизу.
- Каждую модель можно: поднять/опустить стрелками, отправить в самый верх (звёздочка),
  полностью выключить (не участвует даже в авто-режиме) или включить обратно.
- «Сбросить приоритеты» возвращает стандартный порядок.
- Приоритеты действуют и на ручной выбор, и на авто-режим, и на профили.

**Свои эндпоинты (CometAPI и другие)**
- Сколько угодно OpenAI-совместимых серверов: адрес, ключ, список моделей, флаг «видит картинки».
- Переключатель «модели платные — в авто-режим не пускать»: на своих серверах сервер не знает цен,
  поэтому ты сам решаешь, какие из них платные. Платные не участвуют в авто и профилях,
  но их можно выбрать вручную (с предупреждением).
- Кнопка проверки: сервер сам запрашивает `GET /models` и показывает список —
  выбираешь модель из выпадающего списка. Не ответил — впиши модели вручную через запятую.
- Свои серверы участвуют в авто-режиме ПЕРЕД бесплатным Pollinations.

**Ключи** — несколько ключей на каждый провайдер (по одному на строку): исчерпался один —
берётся следующий. При ошибке авторизации ключ уходит в кулдаун сразу для всех моделей.

**Сила размышлений** — лёгкие/средние/сильные: меняет стиль рассуждений
(сильные — по шагам, с проверкой через калькулятор и поиск) + температура отдельно.

**Профили** — Авто / Лёгкие / Сильные (быстрые или самые мощные модели).

**Бесплатно или платно — определяется автоматически.** В реестре — только отобранные
бесплатные модели. При запуске приложения (и кнопкой «Обновить список» в выборе модели)
сервер сверяет цены с живым API OpenRouter: бесплатная = нулевая цена входа и выхода
(`pricing.prompt/completion = 0`). Модель, которая стала платной, получает метку
«платная» и выключается из авто-режима и профилей; новые бесплатные модели
добавляются в список сами. Платную можно выбрать вручную (если есть кредиты).
**Прочее** — маркдаун в ответах (код с кнопкой копирования, таблицы, списки, ссылки),
генерация картинок, поиск в интернете, чтение страниц, точный калькулятор, свой system-промпт.

## Антисон сервера (важно для бесплатного Render)

Бесплатный Render засыпает через ~15 минут без запросов. Приложение FreeNeuro v1.3
решает это само: фоновая служба пингует `/api/health` каждые 5 минут — пока приложение
установлено, сервер не спит, **даже когда приложение свёрнуто**. Включено по умолчанию,
выключается в меню приложения («Сервер не спит: выключить»). Трафик минимальный
(~288 запросов в сутки), батарею почти не ест.

## Установка

### 1. Сервер (бесплатно на Render)
1. Заведи аккаунт на render.com и создай **New → Blueprint**.
2. Закинь файлы проекта на GitHub (этот репозиторий) и выбери его.
3. Render сам прочитает `render.yaml`: Python + uvicorn, порт `$PORT`.
   Никаких ключей серверу не нужно — ключи ты вводишь в приложении.
4. Дождись адреса вида `https://имя.onrender.com`.

Локально: `pip install -r requirements.txt` и `uvicorn main:app --host 0.0.0.0 --port 8000`
(песочница файлов — папка `sandboxes/` рядом с сервером).

Важно про бесплатный Render: диск у него эфемерный — файлы песочницы живут до перезапуска
сервера (передеплоя). Всё, что должно остаться, скачивай кнопкой в файл-менеджере.

### 2. Приложение
- Установи `FreeNeuro.apk` (Android 7+). При первом запуске вставь адрес своего сервера.
- Бесплатные ключи (по желанию, без карты): openrouter.ai/keys, console.groq.com/keys,
  aistudio.google.com/apikey. Без ключей тоже работает — на бесплатной модели Pollinations.

## API (для разработчиков)

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/chat` | чат, SSE-поток (delta/start/switch/tool/image/file/done/error) |
| GET | `/api/models` | реестр моделей, профили |
| GET | `/api/sandbox?chat=` | список файлов песочницы чата |
| POST | `/api/sandbox/upload?chat=` | загрузить файл (multipart, до 50 МБ) |
| GET | `/api/sandbox/download?chat=&path=` | скачать файл (ссылка для «скачать») |
| GET | `/api/sandbox/raw?chat=&path=` | открыть файл (картинки/текст) |
| DELETE | `/api/sandbox?chat=&path=` | удалить |
| POST | `/api/sandbox/move?chat=` | переместить/переименовать `{from,to}` |
| POST | `/api/probe` | `GET {url}/models` — какие модели есть на своём сервере |
| GET/POST/DELETE | `/api/memory[/{i}]` | память |
| POST | `/api/memory/compress` | сжатие памяти нейросетью |
| POST | `/api/summarize` | сжатие истории нейросетью |
| GET | `/api/health` | статус |

Параметры `/api/chat`: `messages`, `model` (id или `auto`/`light`/`strong`/`custom:имя:модель`),
`keys` (`openrouter/groq/gemini` — массивы, `custom` — массив `{name,url,key,models,vision}`),
`chat` (id песочницы), `files` (пути в песочнице для чтения), `model_prefs`
(`order` — порядок моделей, `disabled` — выключенные), `system`, `temperature`,
`reasoning` (`low/medium/high`), `refine` (режим уточнения промпта), `summary`
(сжатая история), `search` (поиск в интернете).

## Как нейросеть читает файлы (как у современных ИИ)
Конвейер на сервере: `.pdf` → текстовый слой (pypdf, до 50 страниц), `.docx` → абзацы и таблицы,
`.xlsx` → листы строками, `.pptx` → текст слайдов, `.ipynb`/код/`.csv`/`.md` → текст,
картинки (png/jpg/webp/gif/bmp) → vision-модели как пиксели без сжатия.
Длинные тексты обрезаются до 20 000 символов — как лимиты контекста у больших чатов.

## Сборка APK
`bash android/build.sh` — aapt2 + javac + d8 + zipalign + apksigner (без Gradle).
Кейстор подписи хранится в `android/freeneuro.keystore`.
